> I hallucinated a library, imported it, and it worked — I've been too scared to check why ever since.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set), validating first that it is one non-blank line of 1–200 characters. No network, no dependencies, no secrets — the same bytes come out of every run.
